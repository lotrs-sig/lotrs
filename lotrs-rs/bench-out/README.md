# Benchmark results

The 14-cell grid uses the production lattice from
[`parameters.json`](../../parameters.json), with `N` and `T` varied as
specified below. All cells use `phi=max(22*T,1100)`.

| Profile | Sign mean | Verify mean | Wire size | Mean attempts |
|---|---:|---:|---:|---:|
| N=32, T=16 | 151.4 ms | 54.56 ms | 42.72 KiB | 3.34 |
| N=100, T=50 | 923.6 ms | 311.0 ms | 53.53 KiB | 5.28 |

For N=100, T=50, signing has a sample standard deviation of 713.2 ms
and median of 718.7 ms. The attempt-count standard deviation is 5.04;
its mean has a standard error of approximately 0.50 attempts. The
4.7728-attempt heuristic is consistent with this observation. The
52.6574 KiB analytic size estimate differs from the measured wire size.

## Reproduction

From the repository root, with Rust and Python/Matplotlib installed:

```sh
cd lotrs-rs
cargo run --release --example bench -- \
  --grid '32,1:4:8:16:32;100,1:5:10:25:50;1,2:4:8:16' \
  > bench-out/grid-d128.md
python scripts/plot_bench.py bench-out/grid-d128.md
```

Allow roughly 15 minutes for the grid on the reference workstation;
slower machines and initial compilation take longer. Plotting takes
under a minute. To preserve the supplied results, use a different output
directory; the plot script writes alongside its input report.

## Measurement method

Each cell uses 100 signing seeds and 100 successful verification calls.
Signing samples are interleaved across cells. Each signing time includes
all attempts needed for one accepted signature. Verification repeatedly
checks the final signature in each cell. Key generation averages four
calls per cell; key aggregation is measured once per cell.

Wire sizes describe the final signature in each cell. The codec uses
lossless Rice coding and fixed-width fields. The report rounds timings
and sizes for display; the CSV parses those rounded values, including
its byte columns. It does not preserve exact unrounded byte counts.
The public key has exactly 9,632 bytes (9.40625 KiB) by the fixed-width
encoding formula; the full N=100, T=50 table is 47,031.25 KiB.

`grid-d128.md` contains timings, means, standard deviations, medians,
attempt counts, and sizes. `data.csv`, `summary.md`, and the five PDF
figures are generated by `scripts/plot_bench.py`.

## Reference environment

- Linux x86_64; AMD Ryzen AI 9 HX 370; 12 cores / 24 hardware threads;
  32 GB RAM.
- rustc 1.98.1 and Cargo 1.98.1; release profile with thin LTO.
- Rayon default thread pool; no CPU affinity or clock controls applied.
- Runtime libraries: rayon 1.12.0, sha3 0.10.9, subtle 2.6.1, zeroize 1.8.2.
- Plotting: Python 3.14.7 and Matplotlib 3.11.1.

Timings depend on processor, thread count, and load. For a comparable
24-thread workstation, a practical reproduction target is within 20%
of the headline means. This is a suggested evaluation tolerance, not a
measured bound on variation across machines. Compare deterministic
fixtures exactly and benchmark sizes at the report's displayed precision.
